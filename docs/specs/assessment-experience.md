# 评估对象与可读结果

实施基点 ee3982bfd061f5bda8c7354206590544cfec6b58。依据用户本轮四项截图反馈及随后 implement 指令，采用上一轮推荐方案。

- 工作区只选择一次评估对象。资产评估按所选资产限定资料；独立软件、镜像保留明确入口。“全部对象”不再暗示批量扫描。未知对象时不显示重复的主机选择器。
- 网络设备的厂商固件评估明确为尚不支持，默认不展示能直接执行的 Linux/Windows 扫描。若其绑定资料确实支持某种系统包评估，按资料能力开放，不能由设备分类推定操作系统。缺少资料、查询失败与正在识别分别说明，关联软件与镜像评估仍可进入。
- Linux 默认按组件展示完整结果，各组显示版本、架构身份、去重 CVE 与等级分布；展开一个组件后组内分页。保留逐条视图，检索/等级改变时清除旧组件选择，未知身份不合并。独立软件/镜像的完整本地结果也按组件分组。
- AI 中文分析支持安全 Markdown 排版，包括标题、列表、表格和代码段；禁止 HTML 执行、图片远程加载及不安全链接。结果先展示资产依据/结论，再解释漏洞、核实事项和建议。可复制 Markdown。
- 失败显示持久任务记录的失败阶段、安全原因及下一步，历史通用错误不伪造精确原因，提供重新解析入口。
- 漏洞来源先在站内查看已有摘要、匹配依据、来源名称、查询/采集时间与证据，再选择打开原文。没有取得原文时明确披露；不把摘要当作已抓取的完整原文。

沿用既有 HTTP 与浏览器验证边界；类型检查、相关浏览器测试、最终全套测试和构建通过后做 Standards/Spec 两轴审查并提交。此次不自动部署。
