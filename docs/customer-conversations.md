# 客户只读风险对话 v1

一个问题形成一条持久对话记录，绑定URL客户和明确选择的最多100次软件评估；不跨客户查找，不自动发起扫描，不改变评估判定。本片支持一个CVE编号，或返回所选评估中的全部工具发现；不自动执行自然语言复杂过滤。公开PHP情报页面与客户对话分别存储。

POST `/api/customers/:customerId/conversations` 输入 `{message,assessmentIds,idempotencyKey}` 返回202；空范围明确not_assessed，不猜当前版本。GET同路径列最近100条摘要，GET `/:id`按需读固定事实及事件。鉴权由全局guard校验URL范围，所有评估引用通过AssessmentService在同一客户内读取。body拒绝customerId、facts、任意查询、工具参数。未知/跨客户编号404，未授权客户403。相同客户/幂等号/原句与评估集合回放同记录；改变问题或范围409。

事实输入在提交时固定：评估状态、输入版本/哈希、工具发现、组件/安装版本、原始适用性、修复依据、coverage与库时间。CVE匹配仅按明确编号；未选择、无可用结果、部分覆盖和可用结果分开，发现数不代表确认受影响数，无匹配不表示安全。原评估后续完成或重扫不会改写已固定的对话；重新提问需新幂等号。

Pi每次使用新进程/会话，只加载 `ys-customer-read` skill及唯一的 `ys_customer_assessment_read` 工具。工具参数为空，读取后端已授权并固定的本次客户资料；模型不提供客户/对象编号，不接触数据库凭据或其他客户文件。工具事件和最终状态保存在对话中。最终展示的事实答复由受控数据渲染，模型自由文本不覆盖事实。Pi未配置、超时或失败时保留已读取的固定事实并明确模型调用未完成。服务器重启将running标中断，不盲目重试；queued可恢复。

使用AppConfig.pi及已有环境配置（见pi-public-query.md），客户只读工具不要求CVE脚本。`runPiCapability` 是共用RPC边界，控制允许工具、callId关联、完成事件、进程超时/输出限制与独立目录。工具允许列表不是OS级沙箱，部署仍需专用服务账号。真实Pi版本、provider及工具加载兼容性未在本次本地验收中验证。

测试使用真实PGlite/HTTP和独立RPC进程替身，包含跨客户引用、无记录、持久回读、幂等冲突、工具快照归属、未授权工具失败及页面客户切换。没有真实模型调用或新扫描。
