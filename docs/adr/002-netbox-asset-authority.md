# 配置NetBox时由其统一管理资产主数据

2026-11-19，accepted。用户明确希望复用NetBox的数据结构，避免再次实现资产主数据系统；配置NetBox的环境以Tenant对应客户，以Device/VirtualMachine对应主机，YS保留外部身份映射、缓存及不可变采集/评估/报告。该决定在NetBox模式下取代ADR001；未配置的既有环境维持显式本地模式，便于分阶段迁移，而不是运行两份可写主数据。

外部身份由实例URL、对象类型、原生ID组成；历史YS编号不变，映射需要显式确认，不按名称/IP合并。NetBox模式关闭原本的本地手工建档；CSV只能关联已同步的明确原生ID，Windows仅关联唯一序列号，未确认资料保留待关联。原生新增/名称及序列号修改先写NetBox，再缓存；超时或失去响应保留不确定操作记录，不自动再次创建。采集得到的资料保留为观测，不回写NetBox当前配置。软件包、运行容器目录与SBOM属于专用观测，不声称是NetBox原生模型或已验证插件能力。

代价是NetBox写入和YS缓存不能共享数据库事务，且真实服务版本、字段和权限仍需单独验收；缓存披露同步时间与可见状态，不能被当作实时主数据。移出Tenant或删除的资产保留历史映射，新的采集必须使用当前有效映射；已有报告事实不受后续同步影响。
