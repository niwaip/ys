# 用户采纳采集资料后形成版本化资产基线

2026-11-19，accepted。用户要求采集后确认、更新NetBox及台账，再次采集突出变化；调用implement视为采纳讨论稿的推荐职责边界。

采集观测不可变，用户选择完整取得的区块并可排除字段，确认后建立带采纳人、时间和来源的基线版本。新采集与最近已确认基线比较；包以包管理器/名称/架构标识，版本变化作为修改，完整清单的缺项才可作为删除。未知字段、失败、权限不足、部分取得不清除原资料。报告复核独立且不改判断。

本决定调整ADR002中“采集不回写NetBox”的规则：明确采纳主机身份时，将主机名、可用序列号映射到NetBox原生name、serial；其他采集分区和完整来源仍保存在YS版本化基线。不会自动创建Platform、IP或覆盖站点/角色等人工配置。该映射在确认界面明确展示，后续字段需要独立映射能力。未配置NetBox时显式保存本地基线。

外部写入与本地确认不能共享事务。先持久化pending确认，再调用幂等写入；失去响应标记unknown、不更新基线、不自动重发，核对远端当前值一致后完成。未知状态阻止该资产后续采纳，防止基线顺序错乱。代价是人工核对流程及显式映射范围，不能把本地成功冒充NetBox已更新。
