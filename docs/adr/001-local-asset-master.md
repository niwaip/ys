# ADR 001：首片使用本地最小资产主数据

日期：2026-11-18。范围：T01 按客户人工创建与查看一项主机资产。

采用本地最小资产记录作为唯一权威主数据。已有 NetBox 是候选集成对象，当前任务没有授权连接或部署已有服务器，首片也不需要 DCIM/IPAM 的完整设施模型。引入远程 NetBox 会使一次人工建档依赖额外部署、身份映射和权限配置，且无法在隔离本地环境完整验收。

本地只保存本片需要的信息：客户归属、内部 UUID、host 类型、名称、人工来源、可选来源标识、JSON 扩展属性、建档时间。客户来自服务端配置，启动写入客户目录；数据库外键保持归属完整性。内部编号与客户、名称、来源编号分开保存。允许同客户和不同客户同名；本片不把名称当去重键。

当前不运行 NetBox 同步、不写第二份权威台账。将来若决定复用 NetBox，需另立 ADR 明确其权威范围、客户映射、外部标识、迁移及同步规则，再由适配模块替换主数据职责，不能让两边默默同时成为权威。

持久化使用 PostgreSQL 参数化 SQL、UUID、timestamptz、JSONB 与版本化迁移。生产可接 PostgreSQL，开发/测试使用 PGlite 的实际 PostgreSQL 引擎实现隔离本地持久化。测试通过 API 重启后回读验证，不以进程内数组模拟数据库。首片没有扫描或风险判定，页面保持“未评估”，不将空发现伪装为无风险。
