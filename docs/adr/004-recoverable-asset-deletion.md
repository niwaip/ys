# 资产删除移除纳管，历史身份和外部主数据保留

2026-11-19，accepted。用户调用implement接受导航与删除任务的推荐边界：删除从YS当前纳管范围移除对象，可恢复，保留采集、基线、评估和报告；不级联删除或同步销毁NetBox原对象，后续同步不自动恢复。该边界避免历史报告失去身份及证据，代价是持续保留资料并明确区分当前纳管与历史范围；永久清理和NetBox删除需要另行设计。

执行中采集/资产关联评估、待核对基线及NetBox写入阻止删除；新写入与删除在同一客户/资产范围内检查状态并持有资产行锁，恢复不会使失效的NetBox映射自动有效。独立软件或镜像SBOM可能被多个资产复用，删除主机不删除这些共享对象。
