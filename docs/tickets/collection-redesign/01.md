## What to build

独立主机基础采集流程，从网页操作到固定来源结果完整可验收。

## Acceptance criteria

- [ ] 顶部统一选择客户所属主机和连接，主机基础资料与容器运行资料为并列可见任务，连接配置收进独立面板。
- [ ] SSH 基础能力检查、采集、结果和历史回读完整可用；新基础采集不访问 Docker 引擎，但允许记录 Docker CLI 软件版本。
- [ ] 支持人工基础资料，缺口明确；不把人工资料声明为运行实例发现。
- [ ] 保留旧连接、授权、快照和原始来源，旧 Docker 字段仅作历史证据。
- [ ] 公共 API 与桌面/手机端到端验证覆盖刷新、客户隔离、无 Docker 权限仍能基础采集。

## Blocked by

None (can start immediately).
