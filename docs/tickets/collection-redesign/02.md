## What to build

独立 Docker 目录发现与镜像扫描衔接，从网页操作到固定来源结果完整可验收。

## Acceptance criteria

- [ ] 容器运行资料有独立动作、目录和状态；未授权入口仍可见并展示配置路径。
- [ ] 检查区分未检查、未授权、工具缺失、访问失败和可用，显示执行主机、身份和检查时间；Docker 和 Trivy 分别检查。
- [ ] 缺少 Trivy 不阻断目录发现，缺少 Docker 不阻断基础采集；提交时重新核验目标及授权。
- [ ] 按固定 ImageID 展示镜像与容器关联，选定后携客户、主机、连接和固定快照进入已有镜像生成与评估流程，不自动扫描全部镜像。
- [ ] 旧 allowDocker 授权沿用，不扩权；API 和端到端验证能力失败、空目录、镜像跳转、历史和客户隔离。
