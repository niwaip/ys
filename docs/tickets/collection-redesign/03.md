## What to build

YS 部署主机的本机采集，从网页操作到固定来源结果完整可验收。

## Acceptance criteria

- [ ] 部署端显式登记已启用的本机执行连接并限定客户及资产，网页选择该连接，明确区别于浏览器电脑。
- [ ] 显示实际执行主机及服务身份，完成基础、Docker、Trivy 能力检查及两类采集。
- [ ] 未登记、跨客户、跨资产和已删除目标不能借本机连接执行；不自动安装、提权或开启 Docker 授权。
- [ ] 新本机连接配置不要求无用的 SSH 密钥与 known-hosts 字段，旧配置保持兼容。
- [ ] 公共 API 与端到端验证绑定校验、能力检查、采集、刷新和历史来源。
