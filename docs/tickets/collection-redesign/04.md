## What to build

Linux 离线采集完整流程，从网页操作到固定来源结果完整可验收。

## Acceptance criteria

- [ ] 按主机基础、容器目录分别下载 Linux 固定采集脚本，执行后产生可上传的完整资料，不需 Trivy 才能发现目录。
- [ ] 网页按选定任务上传并校验范围和归属，明确人工确认归属，保留采集时间、原始产物、hash、来源与未取得范围。
- [ ] 损坏、超限、不支持或范围不匹配资料明确拒绝；相同资料重复上传回读原快照，不截断保存。
- [ ] 离线容器目录可查看镜像和实例并进入已有镜像流程；无在线连接时提示离线镜像 SBOM 生成路径，上传不授予在线权限。
- [ ] 统一历史按任务类型筛选，旧记录回读兼容；API、真实脚本夹具和桌面/手机端到端验证下载、执行、上传、重复与客户隔离。
