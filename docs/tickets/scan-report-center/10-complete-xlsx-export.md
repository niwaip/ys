# 10: 下载完整扫描与整改 XLSX 明细

## What to build

从报告详情为明确修订生成并下载完整明细表，查看文件状态，并在失败时仅重试 XLSX。

## Acceptance criteria

- [ ] 明细表来自固定报告结果，完整保留发现、主机与共享对象关联、适用性、覆盖、生命周期及已有整改依据；不能只导出页面当前分页。
- [ ] 同一镜像的全局发现与涉及主机可分别识别，表格数量与报告统计一致，未知不填零、缺失不伪造。
- [ ] 草稿文件有未复核标识，正式文件受既有复核及交付限制；生成记录绑定明确修订、事实与文件校验信息。
- [ ] 生成和下载状态持久化，失败保留诊断，重试只转换同一固定修订，不重新扫描或覆盖其他已成功产物。
- [ ] 两万条发现完整导出可核对条数与来源，打开文件结构及主要内容有效，表格单元格不能将来源文本意外解释为公式。
- [ ] 有来源整改内容可由报告直接复用，不以可选 AI 或整改扩展工单完成作为硬阻塞。
- [ ] 公开 API、浏览器下载及实际工作簿内容验证通过，包含跨客户与未复核正式导出拒绝。
