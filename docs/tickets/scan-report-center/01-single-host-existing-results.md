# 01: 单台服务器使用已有结果生成固定事实草稿

## What to build

从报告入口选择一台物理服务器或虚拟机，核对当前资料及已有评估，生成可回读、预览和下载未复核 HTML 的固定事实报告，并在报告历史中再次打开。

## Acceptance criteria

- [ ] 默认匹配该主机当前已确认资料版本下最近一次成功的主机漏洞及生命周期评估；允许明确选择历史批次，展示对应资料、时间和最近失败情况，不静默采用旧版评估代表新版资料。
- [ ] 主机、报告任务、明确评估引用、结果集及可用 HTML 产物的身份与状态持久保存；历史报告可按名称、范围、时间和状态识别，客户切换不残留上一客户数据。
- [ ] 冻结主机范围、来源和统计；新版资料及后续扫描不改变已有报告，沿用固定事实哈希和现有内部复核边界。
- [ ] 没有可用结果时仍保留目标及覆盖说明，只生成执行与覆盖说明，不输出整体风险结论；关联软件/镜像尚未纳入时明确披露缺口。
- [ ] 草稿预览和下载明确标注未复核，不绕过现有正式 HTML 的复核与交付限制；任务执行、报告复核、文件状态可分别识别。
- [ ] 既有手工选择评估生成报告及旧报告回读继续工作；必要的内部整理随此闭环完成，不交付孤立的框架或空页面。
- [ ] 通过公开客户 API 和真实浏览器验证单台创建、刷新回读、无结果、旧版本明确选择、跨客户拒绝与历史事实不变。

## Blocked by

None (can start immediately).
