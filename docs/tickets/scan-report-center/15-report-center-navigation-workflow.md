# 15: 切换报告中心入口并验收完整生成交付流程

## What to build

从现有报表入口进入完整报告中心，以五步流程生成报告并完成复核交付，同时继续访问旧报告和旧链接。

## Acceptance criteria

- [ ] 首页集中新建报告和报告历史，五步流程贯通范围、结果来源、覆盖检查、章节/附件配置与任务创建，基于已完成能力接入实际行为而非页面壳。
- [ ] 任务详情集中进度、等待/确认、重试/取消；报告详情集中预览、证据、修订/比较、复核、逐格式状态及下载。
- [ ] 常用列表优先名称、业务状态和结果时间，技术编号/版本/哈希按需查看；刷新、返回、客户切换和移动端均可完成流程。
- [ ] 旧报表链接与历史报告继续读取，旧事实、修订和已交付文件不被迁移改写；菜单切换不误导用户丢失已有结果。
- [ ] 默认包与逐主机/证据选项全部可用，历史比较及可选 AI 接入现有流程，失败保留固定模板路径。
- [ ] 完整验收单台/多台/租户全部、已有结果/新扫描/补扫、采集上传确认、部分/全失败、取消中断、共享对象统计和授权变化。
- [ ] 核对两万条完整导出、PDF 摘要及可选完整模式、文件失败不完整提示、草稿到正式交付和补扫新报告关系；每个前置工单自身仍须已具备公开 API 与浏览器验收。
- [ ] 本工单不包含生产部署，也不通过关闭旧规格或旧工单来表示实施完成。

## Blocked by

- 05：有依据的整改建议与可选 AI 摘要
- 07：重新采集并确认后继续生成扫描报告
- 08：补扫缺失或过期项并恢复中断任务
- 09：历史报告比较与新旧报告关联
- 12：生成可选的逐台服务器分报告
- 13：生成可选的原始扫描证据附件
- 14：打包并交付 PDF、HTML、XLSX 与可选附件
