# 03: 关联软件及镜像纳入报告并分离风险计数

## What to build

在服务器报告中看到明确关联的软件和镜像风险，并从汇总数字下钻到对应发现与主机，避免共享对象重复计数。

## Acceptance criteria

- [ ] 纳入有明确身份、主机关联及资料版本的软件和容器镜像结果；不按名称、标签或相同 CVE 猜测安装/运行关系，待关联资料显示为范围外资料。
- [ ] 逐对象沿用当前资料对应成功评估及历史显式选择规则，缺失、部分覆盖、工具不支持和未知适用性独立披露。
- [ ] 漏洞去重数、发现实例数、涉及服务器数、确认受影响服务器数分离；CVE 与其他漏洞标识保留区别。
- [ ] 共享镜像的一条发现关联三台主机时，全局发现计一次、涉及主机列三台；镜像工具匹配不直接推断三台主机均确认受影响。
- [ ] 漏洞和生命周期风险分别汇总，严重程度保留来源和未知状态，不生成混合风险总分；汇总下钻与统计范围一致。
- [ ] 固定结果集保存主机关联依据，后续解除或新增关联不改变旧报告；完整明细与原始发现可追溯。
- [ ] 公开 API 和浏览器验证共享镜像、同名独立软件、未关联资料、部分确认影响及报告冻结后的关联变化。
