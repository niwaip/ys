# 07: 重新采集并确认后继续生成扫描报告

## What to build

在新扫描中选择先更新资料，连接执行或上传脚本结果，完成既有资料确认后继续评估和生成报告。

## Acceptance criteria

- [ ] 复用主机已保存的采集配置、接入方式和实际能力，明确区分自动执行、脚本上传、确认及评估阶段，不扩展尚未接入的采集能力。
- [ ] 采集观测绑定同一任务及目标，待确认内容沿用现有基线规则；未确认、拒绝或不完整资料不能被冒充可用输入。
- [ ] 脚本等待及待确认状态持久保存，离开页面后可返回继续；返回时恢复对应分项，不按同名对象或其他快照误绑定。
- [ ] 确认后绑定明确新资料版本再评估；陈旧采集时间不由报告生成或重新评估时间替代。
- [ ] 部分采集成功、拒绝确认或不支持的项保留原因，其他项可继续；用户可明确结束等待并生成含缺口报告。
- [ ] 取消后不再派发后续采集或评估，已取得资料与确认记录保留；执行中断明确显示，等待项不因服务重启丢失。
- [ ] 公开 API 和浏览器验证自动路径、上传路径、确认/拒绝、刷新/重启回读及错误目标拒绝；不冒充真实 Windows 或未支持设备执行验收。
