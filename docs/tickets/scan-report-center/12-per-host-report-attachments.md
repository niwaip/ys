# 12: 生成可选的逐台服务器分报告

## What to build

勾选逐台服务器分报告后，为固定范围的每台服务器生成可单独检查和下载的报告，纳入附件选择。

## Acceptance criteria

- [ ] 分报告只引用父报告同一固定修订下属于该主机的事实，保留主机、来源、范围与缺口，不重新选择最新结果。
- [ ] 同一镜像关联多台服务器时，各分报告展示对应关系，总报告仍按共享对象去重；不能由分报告数量推断独立发现数。
- [ ] 没有结果或失败的范围内主机也保留覆盖说明，不因无漏洞明细而静默漏掉文件。
- [ ] 100 台可生成 100 份分报告，逐项显示生成状态及失败原因，只重试失败分报告。
- [ ] 草稿与正式标识、复核权限继承父报告，文件身份与校验值可供最终包清单核对。
- [ ] 公开 API、浏览器及实际分报告内容验证主机隔离、共享镜像、无结果及部分文件失败。

## Blocked by

- 03：关联软件及镜像纳入报告并分离风险计数
- 11：下载摘要及完整明细 PDF 报告
