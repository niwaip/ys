# 08: 补扫缺失或过期项并恢复中断任务

## What to build

只对缺失或过期项补扫，单独重试失败及中断项，或者取消后续执行，避免重复扫描已完成对象。

## Acceptance criteria

- [ ] 使用已确认的新鲜度规则分别识别采集和漏洞评估，默认 7 天可修改；可用且未过期结果复用并保留来源，缺失/过期原因可检查。
- [ ] 只补扫所需对象及已有能力支持的阶段，资料更新仍沿用确认边界；需要资料时显示等待，不声称自动重新采集已完成。
- [ ] 失败与中断项允许单独重试，成功项不自动重放；重复请求不重复派发，记录重试与原任务关系。
- [ ] 取消停止后续派发，保留成功结果与取消/未完成范围；与执行结果并发返回时不覆盖已有固定结果或重复计数。
- [ ] 服务重启后等待项保持，执行中断明确标记，由用户选择重试未完成项，不自动重复外部操作。
- [ ] 报告生成前可选择补扫结果；已有报告后采用新结果形成关联原报告的新报告，旧事实不改变。
- [ ] 公开 API 和浏览器验证补扫范围、取消、重试、重复请求、重启和并发结果；不要求新增采集适配器。
