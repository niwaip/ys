# 09: 历史报告比较与新旧报告关联

## What to build

明确选择一份历史报告，查看可比较范围的问题变化，并区分同报告文字修订与采用新结果产生的新报告。

## Acceptance criteria

- [ ] 仅能选择同一授权客户可访问的历史报告作基准，固定比较双方的报告及结果集，刷新后保持选择。
- [ ] 展示新增、持续、变化及本次未再观察到，单列主机范围、资料版本和评估能力变化；不可比项不混入变化结论。
- [ ] 上次 100 台、本次 80 台，缺失 20 台不计为问题消失；未再观察到不直接宣称已修复。
- [ ] 共享镜像和主机关联按固定结果身份比较，避免关联数量变化制造重复漏洞或修复结论。
- [ ] 补扫或替换评估形成新报告，详情及历史可查看来源报告；只调整文字或呈现形成同事实修订并重新复核。
- [ ] 历史比较在报告正文中按需启用，使用同一固定比较结果；不能读取实时资料而改变旧比较。
- [ ] 公开 API 和浏览器验证范围缩减、资料/能力变化、共享镜像、跨客户拒绝和新报告/修订关系。
