# 06: 从报告任务对已确认资料发起新评估

## What to build

在报告新建流程选择重新扫描，基于已确认的明确资料发起现有能力支持的评估，查看逐项进度后生成新报告。

## Acceptance criteria

- [ ] 选择重新扫描时默认使用已确认的固定资料输入，逐对象展示平台、评估类别、资料版本与实际接入能力，不隐式触发新采集。
- [ ] 报告任务及分项评估引用持久绑定，排队和执行可回读；避免重复提交意外产生重复评估，复用现有评估执行器。
- [ ] 逐主机或对象展示状态、失败及不支持原因，部分成功保留结果，全部无结果仅形成执行与覆盖说明。
- [ ] 评估进行中不把变动结果当作固定报告；生成时固定明确终态结果及缺口，用户可从已有报告发起采用新扫描结果的新报告并保留来源关联。
- [ ] 执行前重新校验客户授权和目标有效性，失效目标停止后续新操作并披露，不将失败解释为零漏洞。
- [ ] 本片即可经现有报告预览及 HTML 路径演示，不以 PDF/XLSX 或重新采集为硬依赖。
- [ ] 公开 API 和真实浏览器验证新评估到报告闭环、逐项失败、重复请求与授权/目标失效；真实外部执行器使用隔离替身。
