# 13: 生成可选的原始扫描证据附件

## What to build

勾选原始扫描证据，按报告冻结的结果下载对应原文，并检查每项证据的来源和完整性。

## Acceptance criteria

- [ ] 仅打包该报告固定结果引用的原始扫描证据，绑定来源任务、对象、资料版本及输出哈希，不重新扫描或以实时结果替换原文。
- [ ] 复用已有授权证据读取能力，共享来源可去重但保留全部引用关系，不暴露其他客户资料或访问凭据。
- [ ] 原文缺失、不可读取、哈希不符独立显示失败，不伪造空文件或用最新原文补齐；允许只重试失败证据项。
- [ ] 选择、证据生成状态及校验信息持久化，支持明确取消失败附件；原报告事实及其他产物保持不变。
- [ ] 草稿及正式证据附件的可访问性继承客户授权和明确报告修订，历史保留不等于持续授权。
- [ ] 公开 API、浏览器下载与原始字节校验验证完整原文、共享证据、缺失/篡改和跨客户拒绝。
