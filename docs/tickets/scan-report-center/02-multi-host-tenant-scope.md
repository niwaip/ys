# 02: 多台及租户全部服务器范围与覆盖检查

## What to build

选择多台或当前租户全部在管服务器，检查每台主机的可用结果和缺口，固定完整清单后生成一份批量报告。

## Acceptance criteria

- [ ] 按当前授权客户及稳定身份选择物理服务器、虚拟机；明确区分当前在管和历史删除资产，待关联资料不能自动归入主机。
- [ ] 范围查询与评估候选完整分页，解除当前 20 个引用和最近 100 次候选对新范围流程的限制，不能截断后声称覆盖租户全部。
- [ ] 创建前显示服务器清单与主数据同步时间，创建时固定清单；运行期间新加入主机不自动纳入，名称或 IP 相同的主机不合并。
- [ ] 逐主机保留成功、失败、等待和未评估，允许部分结果生成报告；100 台中 80 台成功、20 台失败时保留全部 100 台并披露统计范围。
- [ ] 全无可用结果仅给出执行与覆盖说明；未取得结果不显示为零漏洞，生命周期与漏洞覆盖独立显示。
- [ ] 采集资料和漏洞评估分别默认超过 7 天提醒，期限可修改并随报告冻结；明确采用过期结果须披露，生命周期资料不套用该期限。
- [ ] 公开 API 与浏览器验证多选、租户全部、超过现有上限、部分/全无结果、创建期间资产变化、主数据同步信息和客户隔离。
