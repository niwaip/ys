# 11: 下载摘要及完整明细 PDF 报告

## What to build

在报告配置选择默认摘要 PDF 或完整明细 PDF，从详情生成、查看状态并下载，失败时仅重试 PDF。

## Acceptance criteria

- [ ] 默认 PDF 突出管理摘要、服务器风险及重点漏洞，明确筛选规则与未展开数量；用户可选择包含全部明细的 PDF。
- [ ] 使用固定修订的章节及事实，保留范围、覆盖、来源及未知说明；格式转换不改变评估或混用其他修订。
- [ ] 生成及下载状态持久化，文件绑定修订、事实和校验信息；失败可重试，不重新扫描。
- [ ] 草稿带未复核标识，正式 PDF 必须使用已复核并正式交付的明确修订，不能绕过当前交付状态机。
- [ ] 分页、目录、中文字体、表格和长字段可读；大规模两万条发现的摘要能合理阅读，完整模式不静默截断。
- [ ] 公开 API、浏览器下载和 PDF 逐页渲染检查通过，覆盖长内容、空/部分结果及跨客户拒绝。
