# 04: 综合及专题报告章节配置与预览

## What to build

在新建流程选择综合、漏洞或生命周期专题，配置可选章节，预览面向管理人员和运维人员的正式报告结构。

## Acceptance criteria

- [ ] 默认包含封面、管理摘要、范围与覆盖、风险总览、服务器明细、漏洞技术明细、生命周期风险、整改建议、历史对比和证据附录的结构；历史对比在选定基准后才启用。
- [ ] 综合和专题配置可保存、刷新回读，并实际影响固定报告修订的渲染；关闭可选章节不得删除范围、覆盖、未知或必要来源说明。
- [ ] 复用当前已可用的固定结果集，不依赖新扫描、共享对象扩展或新文件格式完成本片演示；相关能力缺失明确披露。
- [ ] 管理摘要与技术章节引用同一固定事实和计数单位，资料时间、扫描时间与报告生成时间不互相填补。
- [ ] 调整章节、摘要、顺序或呈现生成同事实的新修订并重新复核，不能覆盖已交付内容；原评估判定不改写。
- [ ] 公开 API 与浏览器验证模板选择、预览、配置持久化、保护章节、旧报告兼容和修订复核流转。
