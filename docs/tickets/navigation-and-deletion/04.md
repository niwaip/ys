# 04 提供统一CVE与EOSL评估工作区，并从资产发起

**交付：** 用户从评估模块或资产操作入口选择明确对象、固定输入版本与评估类型，提交已有能力支持的任务并查看结果。

**Blocked by：** 02（评估模块入口）。

验收：
- 汇集已有软件SBOM、镜像SBOM、Windows补丁CVE评估及EOSL评估；不重复实现现有执行器。
- 从资产发起时保留资产及明确关联的输入版本；不能误选同客户其他主机的软件版本作为部署事实。
- 显示支持范围、配置状态、排队/执行/失败/完成、覆盖和证据；未配置或不支持不展示为零风险。
- 主机Linux原始包清单与运行容器组件扫描的现有限制明确显示；新扫描适配器另行立项。
- 结果与固定输入版本绑定，可刷新回读及查看历史，保持客户隔离；单独发起软件评估仍可用。
- EOSL针对已维护的生命周期资料执行匹配，与资料维护分离。
