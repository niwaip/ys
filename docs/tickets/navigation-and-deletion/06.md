# 06 Dashboard汇总当前客户资产与风险，并能下钻

**交付：** 首屏汇总当前客户资产、CVE、EOSL风险及覆盖情况，点击数字或图表进入与统计口径一致的明细。

**Blocked by：** 01（在管/删除的统计边界）、02（首屏与模块导航）。

验收：
- 基于已有评估结果实现汇总，不依赖04/05工作区改造；缺少评估时仍可显示资产与覆盖缺口。
- 资产统计按明确对象类型展示，不把主机、软件、容器镜像或组件混为同一数字。
- 展示去重CVE数、受影响对象数、严重程度、EOSL及临近到期、未评估/资料不足、趋势和统计时间。
- 已删除资产默认不计当前纳管风险；历史趋势及固定报告保持原口径，并披露是否包含历史资产。
- 当前选定/有效评估版本与历史运行次数分开，防止重扫重复累计；未知状态单列。
- 图表和列表下钻条件一致，不仅停留在数字卡片；客户切换、空数据、移动端及多对象复用组件验收通过。
