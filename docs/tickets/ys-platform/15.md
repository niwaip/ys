# T15：内部复核报告并导出正式修订

状态：拟发布任务草案，待拆分审批；尚无 GitHub issue 编号。

## What to build

内部人员编辑报告表述与布局、完成复核，并导出绑定依据的正式报告修订。

## Acceptance criteria

- [ ] 提供草稿编辑、提交复核、复核通过和正式交付的最小流程，记录操作人员及修订信息。
- [ ] 编辑范围限于报告文字、结构和呈现；受控事实与正式输出在交付前校验，不能人工修改评估判定。
- [ ] 报告依据、范围、时间及覆盖缺口随交付输出保留，报告复核不改变原始风险统计。
- [ ] 通过后的内容修改形成新修订并重新复核，已交付版本保持可追溯。
- [ ] 首个建议交付格式为可独立查看的 HTML，具体格式在本片实施前明确；Word、Excel、PDF 可后续独立扩展。
- [ ] 固定模板草稿和经过校验的 AI 草稿使用同一复核接口，因此本片不阻塞于 AI 叙述任务。
- [ ] 通过接口与页面验收未复核禁止正式交付、修订重审、事实偏移拒绝及客户隔离。
