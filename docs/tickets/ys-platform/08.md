# T08：导入生命周期主数据并展示 EOS/EOL 评估

状态：拟发布任务草案，待拆分审批；尚无 GitHub issue 编号。

## What to build

导入有来源的生命周期资料，为客户资产匹配产品阶段，在独立页面查看日期、状态和证据。

## Acceptance criteria

- [ ] 首片支持一个说明字段含义的生命周期 CSV 契约，保留来源、导入批次、内容校验和阶段含义。
- [ ] 按客户对象、产品和已取得的版本资料匹配，展示匹配依据和置信或核实状态。
- [ ] EOS/EOL 阶段独立于 CVE 展示；无法匹配、未知日期或弱匹配不能伪装成已核实状态。
- [ ] 同条记录一个日期无效时保留其他有效信息；不以导入或评估时间代替未知日期。
- [ ] 新的主数据批次及评估可追溯，历史依据不被静默改写，重复导入行为明确。
- [ ] 通过接口和页面验收精确、弱匹配、未匹配、阶段差异、坏日期和客户隔离。

## Blocked by

- T02：预览并导入一份 CSV 资产清单

## Scope notes

导入生命周期来源资料不等于人工修改已生成判定；首片不承诺完整厂商覆盖或自动抓取全部公告。

每条任务通过业务接口和必要页面行为验收；相关持久化、执行逻辑和测试随该行为共同交付。客户归属、来源追溯和失败语义从本片开始落实，不推迟到统一补丁任务。
