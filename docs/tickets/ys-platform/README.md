# YS 纵向任务拆分草案

状态：用户已调用 implement-spec 进入实现；任务发布及进度以 GitHub 记录为准。

来源：当前对话和资产风险平台规格。GitHub 项目为 niwaip/ys；父规格为 #1，T01–T15 为 #2–#16，已设置原生子任务及阻塞关系。

## 共用约定

- 每条任务贯穿所需数据、后端业务接口、前端交互和行为测试，交付一个可以演示或验证的完整用户行为。
- 建议以 TypeScript、Node.js LTS、React + Vite、NestJS、PostgreSQL 为起点；具体依赖及资产主数据来源在首片中明确，框架仍按用户评审结果落实。
- 主验收边界建议采用后端面向前端的业务接口，补充少量关键浏览器流程；本次拆分审核一并审阅此验收方式。
- 任务覆盖首版可交付路径，不承诺一次支持所有资产类型、SBOM 格式和厂商。CycloneDX JSON、CSV、Windows 采集 JSON 与 HTML 交付是拆分建议，尚未单独确认。
- 公开情报查询与客户评估分别记录。报告复核只调整报告表达和呈现，不修改评估判定。
- 用户登录和客户访问权限按最终账号方案落地；任何可用实现从首片起都必须由后端校验客户范围，不允许先交付无隔离的数据访问。
- 阻塞只列直接前置，不重复列传递依赖；发布时替换为 GitHub 原生 blocking 关系。
- 所有任务单独保存并发布为 ready-for-agent；当前本地实现由后续 implement-spec 调用授权，不包含服务器验证或部署。
- 当前没有业务代码，因此不另建重构或基础设施横向任务。所需最小框架、任务记录及持久化随第一个使用它的业务片交付。

## 任务总览

1. **按客户创建和查看一项资产**（[完整草案](01.md)）
   - 阻塞：无，可开始。
   - 交付：在工作台选择客户，手工建立一项资产并刷新查看；不同客户的同名资产保持独立。

2. **预览并导入一份 CSV 资产清单**（[完整草案](02.md)）
   - 阻塞：T01。
   - 交付：为客户上传 CSV，预览字段映射及问题记录，提交后查看资产与原始资料。

3. **导入固定脚本产生的主机采集 JSON**（[完整草案](03.md)）
   - 阻塞：T02。
   - 交付：上传脚本采集 JSON，在同一客户下查看主机快照、软件和补丁信息，并保留采集完整性。

4. **上传软件 SBOM 并查看组件清单**（[完整草案](04.md)）
   - 阻塞：T02。
   - 交付：上传一份 CycloneDX JSON SBOM，关联客户的软件对象及版本，并在页面查看组件与来源。

5. **从页面执行 Trivy 软件评估并保存结果**（[完整草案](05.md)）
   - 阻塞：T04。
   - 交付：对已上传软件 SBOM 发起后台 Trivy 任务，查看执行进度、漏洞明细、证据及覆盖情况。

6. **评估容器 SBOM 并关联镜像身份**（[完整草案](06.md)）
   - 阻塞：T05。
   - 交付：上传容器镜像的 SBOM，关联镜像身份与版本，复用 Trivy 任务查看容器组件风险。

7. **基于主机资料进行有补丁依据的 Windows CVE 评估**（[完整草案](07.md)）
   - 阻塞：T03、T05。
   - 交付：选择已导入的 Windows 主机快照，执行固定评估流程并查看系统 CVE、修补依据和无法确认的部分。

8. **导入生命周期主数据并展示 EOS/EOL 评估**（[完整草案](08.md)）
   - 阻塞：T02。
   - 交付：导入有来源的生命周期资料，为客户资产匹配产品阶段，在独立页面查看日期、状态和证据。

9. **通过 Pi 对话完成一次公开 PHP CVE 查询**（[完整草案](09.md)）
   - 阻塞：T05。
   - 交付：在对话中输入 PHP 漏洞查询，后台调用 Pi 与固定 skill/脚本，显示执行过程、来源和查询结果。

10. **通过客户对话查询和解释已有评估**（[完整草案](10.md)）
   - 阻塞：T09。
   - 交付：在客户上下文中对话查询已保存的软件风险和证据，例如询问该客户哪些组件涉及某个 CVE。

11. **重扫后查看历史并比较评估版本**（[完整草案](11.md)）
   - 阻塞：T05。
   - 交付：同一软件对象有新资料或重新评估时，查看每次结果与其依据，并比较发现的变化。

12. **按客户查看可下钻的风险 Dashboard**（[完整草案](12.md)）
   - 阻塞：T08、T11。
   - 交付：从客户概览查看资产、组件、CVE、生命周期、覆盖及趋势，并下钻到对象和证据。

13. **生成绑定评估依据的事实报告草稿**（[完整草案](13.md)）
   - 阻塞：T05、T08。
   - 交付：选择客户和评估范围生成可预览的报告草稿，展示 CVE、生命周期、统计和证据来源。

14. **用 Pi 生成并校验报告叙述**（[完整草案](14.md)）
   - 阻塞：T09、T13。
   - 交付：基于报告事实输入，通过 Pi 生成摘要与解释，预览保留依据且不会偏移事实的报告草稿。

15. **内部复核报告并导出正式修订**（[完整草案](15.md)）
   - 阻塞：T13。
   - 交付：内部人员编辑报告表述与布局、完成复核，并导出绑定依据的正式报告修订。
