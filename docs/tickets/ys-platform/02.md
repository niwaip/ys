# T02：预览并导入一份 CSV 资产清单

状态：拟发布任务草案，待拆分审批；尚无 GitHub issue 编号。

## What to build

为客户上传 CSV，预览字段映射及问题记录，提交后查看资产与原始资料。

## Acceptance criteria

- [ ] 支持一个公开说明的 CSV 输入契约；以客户、来源及对象标识为核心，允许来源特有扩展字段。
- [ ] 预览显示映射结果、缺失字段、重复或歧义记录；明确整批提交或部分提交规则。
- [ ] 采集时间和导入时间分别表达；原始资料、内容哈希、处理结果与已导入对象可追溯。
- [ ] 重复提交不会无提示地创建副本；不同客户上传相同内容仍保持业务归属独立。
- [ ] 问题记录不会被展示为成功导入；来源字段缺失不由 AI 自动编造。
- [ ] 通过接口和上传页面验收有效、无效、混合、重复与跨客户输入。

## Blocked by

- T01：按客户创建和查看一项资产

本片只实现 CSV，不承诺自动识别任意文件或实现所有导入器。

每条任务通过业务接口和必要页面行为验收；相关持久化、执行逻辑和测试随该行为共同交付。客户归属、来源追溯和失败语义从本片开始落实，不推迟到统一补丁任务。
