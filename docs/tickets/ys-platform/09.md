- [ ] 后端封装 Pi 调用与任务状态，前端对话展示消息、工具执行和失败原因；进程通信方式在本片明确。

- [ ] 展示产品范围、时间条件、结果和覆盖缺口，离线或来源失败不由模型记忆补成最新查询。

- [ ] 默认使用可替代 Pi 及固定查询输出验收消息、工具结果、超时、失败和刷新回读。
