# T13：生成绑定评估依据的事实报告草稿

状态：已发布为 GitHub #14，进入实现。

https://github.com/niwaip/ys/issues/14

## What to build

选择客户和评估范围生成可预览的报告草稿，展示 CVE、生命周期、统计和证据来源。

## Acceptance criteria

- [ ] 报告选择明确的客户、对象、资料和评估版本；不读取未授权客户资料。
- [ ] 先使用固定模板生成事实草稿，统计、标识、判定、版本和日期能对应具体评估记录。
- [ ] 涵盖 CVE 与 EOS/EOL 独立内容，并说明未评估、部分覆盖、未知日期和数据新鲜度。
- [ ] 保存报告事实输入及引用，后续重扫不会静默改变已生成草稿。
- [ ] 前端可预览草稿并进入依据明细；不依赖 Dashboard 或 Pi 才能生成事实草稿。
- [ ] 使用固定评估数据验收内容、统计及版本一致，缺少数据时不编造。
- [ ] 为后续 AI 叙述与内部复核提供稳定报告契约，草稿尚不代表通过复核。

## Blocked by

- T05：从页面执行 Trivy 软件评估并保存结果
- T08：导入生命周期主数据并展示 EOS/EOL 评估

## Scope notes

本片不实现 AI 叙述或正式交付，保留固定模板作为后续可用路径。

每条任务通过业务接口和必要页面行为验收；相关持久化、执行逻辑和测试随该行为共同交付。客户归属、来源追溯和失败语义从本片开始落实，不推迟到统一补丁任务。
