## What to build

上传脚本采集 JSON，在同一客户下查看主机快照、软件和补丁信息，并保留采集完整性。

## Acceptance criteria

- [ ] 首个适配器使用已讨论的 Windows 采集资料结构，并公开支持的版本和字段含义。
- [ ] 资产身份关联、原始资料保留和处理记录复用既有导入行为；身份歧义得到待确认状态，不按同名静默合并。
- [ ] 展示系统版本、Build/UBR、软件和 KB 清单，以及来源提供的采集状态；缺失字段保持未知。
- [ ] 新采集形成独立资料版本或快照，不静默覆盖既有评估依据。
- [ ] 扩展字段继续可追溯，接口与页面明确说明哪些资料可支持后续评估。
- [ ] 使用固定采集资料验收正常、部分采集、未知版本、重复和身份冲突情况。
