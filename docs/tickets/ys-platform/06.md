# T06：评估容器 SBOM 并关联镜像身份

状态：拟发布任务草案，待拆分审批；尚无 GitHub issue 编号。

## What to build

上传容器镜像的 SBOM，关联镜像身份与版本，复用 Trivy 任务查看容器组件风险。

## Acceptance criteria

- [ ] 首片支持容器镜像 CycloneDX JSON SBOM，展示镜像来源、可取得的 digest 与标签；身份不足明确提示。
- [ ] 复用既有导入及执行契约，保存操作系统或包生态信息，不把容器标签当作不可变全局身份。
- [ ] 结果关联正确镜像资料版本，并与同客户的软件应用清楚区分。
- [ ] 镜像内发现不自动归属于未经关联确认的运行实例。
- [ ] 支持从镜像详情进入组件、漏洞和证据，工具失败及库过期沿用现有披露方式。
- [ ] 以固定容器资料验收版本区分、组件映射、重复输入和跨客户隔离。

## Blocked by

- T05：从页面执行 Trivy 软件评估并保存结果

## Scope notes

本片只接收已生成 SBOM；直接连接镜像仓库、Docker daemon 或客户集群另行明确。

每条任务通过业务接口和必要页面行为验收；相关持久化、执行逻辑和测试随该行为共同交付。客户归属、来源追溯和失败语义从本片开始落实，不推迟到统一补丁任务。
