# T04：上传软件 SBOM 并查看组件清单

状态：拟发布任务草案，待拆分审批；尚无 GitHub issue 编号。

## What to build

上传一份 CycloneDX JSON SBOM，关联客户的软件对象及版本，并在页面查看组件与来源。

## Acceptance criteria

- [ ] 支持一个明确版本范围的 CycloneDX JSON 输入，拒绝或说明不支持的格式和结构。
- [ ] SBOM 关联具体软件对象与版本；组件名称、版本、包生态及存在的 PURL 等身份信息可查。
- [ ] 保留原始 SBOM、扩展资料、内容校验信息和导入记录，缺失版本不被补造成确定值。
- [ ] 资产、应用与组件具有可解释关系；相同组件出现在不同对象中不会导致客户或版本串联。
- [ ] 新 SBOM 可作为新输入版本保留，重复上传行为有明确结果。
- [ ] 通过接口和页面验收组件清单、来源追溯、坏文件与跨客户关联限制。
- [ ] 新增 SBOM 适配器复用 CSV 导入已有的客户、来源与处理结果契约；既有 CSV 行为验收仍通过，变更集中在相应功能模块。
