# T14：用 Pi 生成并校验报告叙述

状态：拟发布任务草案，待拆分审批；尚无 GitHub issue 编号。

## What to build

基于报告事实输入，通过 Pi 生成摘要与解释，预览保留依据且不会偏移事实的报告草稿。

## Acceptance criteria

- [ ] 通过已有 Pi 任务能力调用报告 skill 与固定脚本，输入绑定已生成报告事实及范围。
- [ ] AI 组织摘要、解释和建议，数字、CVE、版本、日期及评估判定依据固定事实输入校验。
- [ ] 生成内容无法通过校验时保留可诊断原因，拒绝越界段落或降级固定模板，不改写评估结果。
- [ ] 页面展示生成进度和草稿版本，失败不会丢失已有事实草稿。
- [ ] 向模型传递的资料限定为报告范围所需内容，不混入其他客户信息。
- [ ] 以固定模型输出验收正常、虚构标识、统计偏移、未知日期被填充、超时和降级行为。
