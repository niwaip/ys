# T07：基于主机资料进行有补丁依据的 Windows CVE 评估

状态：拟发布任务草案，待拆分审批；尚无 GitHub issue 编号。

## What to build

选择已导入的 Windows 主机快照，执行固定评估流程并查看系统 CVE、修补依据和无法确认的部分。

## Acceptance criteria

- [ ] 首片限定一个明确公布的 Windows 产品线；具体产品线与可复用旧规则在实现前记录，不宣称覆盖所有 Windows。
- [ ] 根据可追溯的产品、Build/UBR、KB 及来源证据进行评估，保留工具与规则版本。
- [ ] KB 替代关系来自可核实来源，不按编号大小推断，也不把缺少 KB 记录直接等同于未修复。
- [ ] 部分采集、补丁清单不完整或待重启等条件在判定与页面中得到保守处理。
- [ ] 通过已有任务和结果接口发起、查看与回读，未知、可能受影响、受影响和已修复等状态有明确依据。
- [ ] 使用固定公告与采集资料验证同分支构建比较、替代 KB、缺失证据及待重启情形。
