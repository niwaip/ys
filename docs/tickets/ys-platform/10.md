# T10：通过客户对话查询和解释已有评估

状态：已发布为 GitHub #11，进入实现。

https://github.com/niwaip/ys/issues/11

## What to build

在客户上下文中对话查询已保存的软件风险和证据，例如询问该客户哪些组件涉及某个 CVE。

## Acceptance criteria

- [ ] 会话明确客户归属，后端和工具接口共同校验访问范围，不依赖提示词单独隔离。
- [ ] 首个固定能力只读已有软件评估、组件及证据，回复能关联到实际记录和来源。
- [ ] 当前客户的无结果、未评估和评估失败分别说明，不能把其他客户的资料补入回复。
- [ ] 公开漏洞资料与客户受影响结论分别表达，解释不改变保存的评估判定。
- [ ] 工具调用和证据引用可从对话回读，不自动产生新的正式扫描。
- [ ] 接口及对话验收客户切换、伪造对象引用、无记录、证据不足和跨客户访问。

## Blocked by

## Scope notes

首片不通过对话自动触发重扫或修改客户环境，这些动作规则需另定。
