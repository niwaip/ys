# 报告中心布局与视觉整理

2026-11-24，针对用户反馈“页面太丑、布局不合理”，将报告中心从原生表单纵向堆叠整理为独立工作区。比较基点 `f0a121e`。

## 界面变化

- 顶部按当前客户最近 100 份报告呈现近期报告、草稿、待复核及已交付数量，保留显式统计范围。
- 创建区使用横向五步流程，桌面左侧向导、右侧近期报告；范围和名称表单按字段关系排列，覆盖检查展示独立数字卡片。历史支持名称/编号搜索，无名称的旧报告使用可读标题。
- 报告任务独立成卡片，状态、服务器数量、时间及主要操作分层；逐项详情与失败重试保留。
- 打开报告切换到详情工作区，创建向导及任务不再占据上方空间。预览、文件交付、编辑复核、来源依据通过四个标签页切换；支持方向键、Home/End 及明确选中状态。
- 预览优先展示；文件包分组展示 PDF/HTML/XLSX/证据、大小、状态与下载。草稿及正式包的状态保护保持原样。
- 受控叙述编辑与操作审计默认收起，复核和交付操作独立成组。长编号与 SHA-256 收进标识校验详情，避免占据主要阅读空间。
- 统一圆角、边框、字号、间距、表单、复选框和状态色。CSS 均限定报告中心类名；手机单列排列，文件按钮换行，长名称不撑宽页面。未调整其他页面全局样式、API、权限、扫描规则或数据库。

## 验证

`npm run build`：类型检查及生产构建通过，保留原有单包体积提示。`git diff --check` 通过。

报告中心四条真实浏览器路径通过：单台/租户生成及修订、390 宽新评估与正式交付、多主机历史比较、逐项重试。补充断言横向步骤在同一行、标签键盘切换及手机无横向溢出；旧报告、Linux 依据、受控叙述及复核流程同步适配新的显式入口。

完整浏览器回归执行 46 项：44 项通过、1 项需独立 Pi fixture 而跳过，另 1 项旧软件扫描用例超过默认 5 秒等待。保存原测试库后，用干净测试库仍复现，排除累积数据作为唯一原因。定点探针测得后台约 4.3 秒成功，页面随后正常拿到结果；调整该异步断言等待上限为 15 秒后，独立复跑通过（7.8 秒）。因此 45 项非跳过行为均完成通过验证；未改扫描实现，临时探针已删除。保留原测试库于本地忽略目录 `.data/browser-test-before-report-redesign`。
