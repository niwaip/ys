## 用户流程

- 主机与执行位置统一选择，主机基础、容器运行资料为并列任务；连接配置独立管理。
- 主机基础采集不访问 Docker 引擎；容器目录可独立发现，不要求 Trivy。能力状态及执行身份、主机、检查时间明确展示。
- 已登记 YS 部署主机可省略 SSH 字段；继续按客户、资产和授权控制，不开放任意本机执行。
- 两类 Linux Node.js 离线脚本独立下载，生成 ys-host/1 后确认归属并上传，保留原始来源及 hash；人工登记不能冒充目录发现。
- 固定目录跳转保留主机、快照及连接，刷新不会自动发现新目录或扫描全部镜像；历史类型分页筛选由服务端执行。

## 边界
