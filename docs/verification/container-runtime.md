# 容器主机镜像生成与扫描验收

范围：选择主机与已授权 Docker 连接、镜像发现、固定 ImageID 生成 SBOM、服务端漏洞评估、手动/离线上传、批量与显式重试、主机及客户风险概览概要。

## 验证

- API 公共接口专项：7 项通过，覆盖大 SBOM、客户隔离、来源和原始证据、请求幂等、并发导入原子性、运行中评估状态、重启历史、离线无标签镜像包。
- 专项浏览器端到端：桌面和手机 2 项通过，覆盖发现、批量生成/扫描、部分失败/重试、固定结果与来源、手动上传、离线下载、Dashboard 跳转及刷新。
- 旧镜像页面端到端回归通过。
- TypeScript 与生产构建通过。
- 全量 API 回归：29 个文件、85 项通过。默认浏览器回归 23 项通过、1 项按原条件跳过；另 1 项生命周期用例因保存请求等待不足超时，补充等待“处理记录已保存”后单独重跑通过（5.4 秒）。合计 24 项默认浏览器用例验证通过，另有 2 项容器专项。
- 实际工具烟测：在目标服务器创建独立临时 scratch 镜像，执行真实 Docker/Trivy 0.76.2 生成 CycloneDX 1.7，经真实解析器验证后删除临时镜像。没有扫描现存业务镜像。

## 审查

基点：`43c6ea4d7224d0a0c1459cd3dc7794e573acd14d`。独立 Standards / Spec 审查发现并修复：评估 `running` 错判为终态；离线脚本未规范化 Docker 空标签/摘要列表。均先以公共 API 测试复现，再修复验证。Spec 审查已复核两项修复解决。未发现硬性仓库标准违规。

## 使用条件

自动路径需要已授权 Docker 连接、目标已准备 Docker 与 Trivy。不会自动安装工具、提权、拉取镜像或扩大生产连接授权。也可手动上传 CycloneDX 1.4–1.7，或下载离线脚本在主机生成后上传。镜像漏洞及历史运行观测不等同于主机已确认受影响。
