## 交付行为

报告中心五步流程支持单台、多台、租户全部服务器；冻结服务器清单、关联版本、结果及比较基准。已有结果可逐对象选择历史批次；新评估与采集确认复用既有服务。增量分别检查采集和评估新鲜度，采用旧资料需明确选择。取消、选择性重试及服务重启不隐式重放外部任务。

综合、漏洞、生命周期专题共用固定事实；编辑呈现产生新修订并重新复核。共享对象独立去重，关联宿主不自动算确认受影响。完整 XLSX、摘要/完整 PDF、离线 HTML、可选逐主机 PDF 与原始证据组成带校验清单的 ZIP；文件失败独立保留，正式交付受指定修订复核状态约束。

接口、运行依赖与具体限制见[报告中心](../report-center.md)。本轮没有部署生产。

## 交付边界

Linux 新评估沿用当前 dpkg 能力；Windows 使用明确导入的离线规则，保留部分覆盖。采集能力或配置不足时明确等待或缺口，不承诺自动采集所有平台。关联 SBOM 过期时需重新生成并关联新版本后创建新报告，或明确采用原资料。PDF 服务需安装 Chromium/Chrome 及中文字体，缺少依赖只使 PDF 文件失败，允许补齐后重试。

验证覆盖分布在公开 API 和真实浏览器层；没有将所有工单逐条表述为每个平台均完成实机验证。工单保持 OPEN，合并及验收前不提前关闭。
