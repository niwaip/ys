## 复现及根因

主机存在可扫描快照，但未选择快照时点击“建立新扫描请求”，原处理器仅更换幂等键并清除job，没有选择输入、焦点变化或反馈。主扫描按钮继续禁用，用户看到无反应。

修复前在真实8001运行本地忽略目录脚本output/deployment/repro-new-scan.mjs，点击后断言“扫描所选Linux快照”可用，失败为Received:disabled。随后增加浏览器回归测试，修复前因缺少“新扫描请求已准备”状态提示而失败。

## 修改后的行为

- 保留当前已选且支持扫描的快照；未选时选中当前批次首个支持扫描的快照。
- 生成新的幂等键、清除旧结果/错误，将焦点移到快照并显示发行版、包数、接入时间及下一步提示。
- 仍需核对后点击“扫描所选Linux快照”才发送扫描请求。准备按钮不会静默启动扫描。
- 当前批次无可用快照或仍在加载时给出明确状态，不提交空任务；手动换快照后清除旧提示。
