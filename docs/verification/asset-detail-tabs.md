# 资产详情展示与采集复核分离

2026-11-19，按用户最新反馈调整：

- 资产台账详情只读，默认显示已确认基础数据；可查看最近采集变化，但不提供采纳、确认、核对或放弃写回操作。
- 确认与更新基线只保留在资产采集的资料详情内。
- 主机身份、操作系统、硬件、网络、系统包、Docker 环境、容器、软件 / 项目组成八个 Tab。Docker 环境合并客户端、引擎；容器分区展示容器与镜像目录。底层权限与采集范围仍独立。
- 软件和镜像组件读取该客户、该主机显式关联的固定 SBOM 版本，可搜索及分页；关联列表按主机和类型在服务端过滤，再分页。客户所有 SBOM 不会自动视作本主机部署内容。
- 当前容器组件扫描尚未接入；镜像 SBOM 明确不覆盖容器可写层与挂载卷。没有资料时不展示零漏洞或已扫描。

验证：原确认按钮回归测试先失败；修改后台账只读、主机关联软件组件、再次采集差异测试通过。采集结果确认入口实际提交并更新基线的浏览器测试通过。接口与单元测试23文件63项通过，生产构建通过。

代码复核：Spec未发现问题；Standards发现合并Tab遗漏Docker/镜像变更数量，已改为汇总各底层分区。
