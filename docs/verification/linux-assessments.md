## 实际发现并修复的缺陷

1. Ubuntu仅有os-release时，Trivy未识别发行版。固定采集补充lsb-release；识别不一致时失败，不保存假零漏洞。
2. held包的Status是`hold ok installed`，仍属已安装。以状态末尾判断，保持完整包清单校验。
3. Trivy原生包版本拆为epoch/Version/Release。重建后按名称、完整版本及可用架构核对，避免把已识别包误作覆盖缺口。
4. 下拉框长文本撑宽手机。限制选择器宽度，添加390宽度回归。
5. 约85MB原始报告和重复逐条漏洞描述造成PGlite历史查询53200内存不足。改为gzip保存一份原始报告，发现以原文哈希和数组位置精确引用；查询只投影所需字段，轮询串行并在终态停止。

针对第5项，在造成失败的部署备份副本上转换两条历史扫描，逐条校验任务ID、状态、发现数量和解压后的完整原文不变；历史查询199毫秒完成。旧格式启动转换及连续两次重启的API回归通过。原始报告、发现数量及判定不因存储转换而修改，早先诊断批次仍作为独立历史保留。
